# How to start a new DH repo

**Moved to [dighum_template](../../dighum_template/docs/NEW_REPO.md).**

This file is kept as a pointer. The canonical template repo is `~/develop/dighum_template`.

```bash
cd ~/develop/dighum_template
./scripts/bootstrap.sh ~/develop/MyNewProject my-new-project
```

Or via the deprecated forwarder in this repo:

```bash
cd ~/develop/republic_ner_matching
./scripts/bootstrap_dh_project.sh ~/develop/MyNewProject my-new-project
```
